# 食譜與資料來源評估（SOURCES）

> 依方案書 §4.4：排除 AI 生成內容的網站；官方／學術來源優先。
> 狀態：條款核實完成第一輪（2026-10-29，由 AI 助手以 web_search／webfetch 讀取條款原文）。凡標「未能核實」的項目，開發爬蟲前必須由人工補查。
> 本檔只記錄「實際讀到的條款原文」；法律意見不在此範圍，正式上線前建議由人工再覆核一次。

## 評估準則
1. 非 AI 生成（有真實作者／機構、成品實拍、來源註明）
2. robots.txt 允許；服務條款（ToS）不禁止抓取
3. 授權清晰（政府開放授權優先）
4. 有結構化資料（JSON-LD）或開放資料格式（CSV/JSON/API）

結論標記：**可用** = 條款明確允許；**需授權** = 條款禁止或未允許，須取得書面同意；**不可用**；**未能核實**。
