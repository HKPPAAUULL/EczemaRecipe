# 食譜與資料來源評估（SOURCES）

> 依方案書 §4.4：排除 AI 生成內容的網站；官方／學術來源優先。
> 狀態：條款核實完成第一輪（2026-10-29，由 AI 助手以 web_search／webfetch 讀取條款原文）。凡標「未能核實」的項目，開發爬蟲前必須由人工補查。
> 本檔只記錄「實際讀到的條款原文」；法律意見不在此範圍，正式上線前建議由人工再覆核一次。

## 評估準則
1. 非 AI 生成（有真實作者／機構、成品實拍、來源註明）
2. robots.txt 允許；服務條款（ToS）不禁止抓取
3. 授權清晰（政府開放授權優先）
4. 有結構化資料（JSON-LD）或開放資料格式（CSV/JSON/API）

結論標記：**可用** = 條款明確允許；**需授權** = 條款禁止或未允許，須取得書面同意；**不可用**；**未能核實**。

### E3. 授權矛盾風險：《性格馬祖II 食膳馬祖》與 OGDL 標示

**事實（已讀）**

- 國家文化記憶庫上**無法用站內搜尋找到名為「食膳馬祖」的物件**（`q=食膳馬祖` 0 筆）。馬祖食譜物件標題為「食譜─○○」，**描述欄未註明取自《食膳馬祖》**；已讀的「食譜─」7 筆「資料來源」欄只顯示「國家文化記憶庫」。因此「該 20 道＝《食膳馬祖》內容」**只是推測、未證實**。可佐證的是：GPI 書介（<https://gpi.culture.tw/books/1009903593>）列「老酒黃魚、清蒸佛手、炸酒糟鰻、紅糟雞湯」等菜式，與記憶庫標題（老酒黃魚、清蒸佛手、炸紅糟鰻、紅糟雞湯）相近，但「相近」不等於同一文本。
- 出版品資訊：GPN 1009903593、2010/11（國家網路書店作 2010-12）、連江縣政府出版、96 頁；GPI「授權資訊」：「著作財產權管理機關或擁有者：連江縣政府」；「取得授權資訊：聯絡處室：建設局 姓名：曹正瑞 …」。GPI 頁面**未載明任何公眾授權（如 OGDL／CC）**。
- 記憶庫標示 OGDL 的依據：tcmb 使用條款稱貢獻者（含建檔單位）於提交時「已透過契約簽訂、貢獻條款同意之方式向網站擔保」其為有權處分人，並「依貢獻時標示之具體條件」提供公眾近用；授權規範頁稱標示由網站「將各機關所提供的資料…進行授權分類及對照」並加註「權利標示仍須以原始資料來源之權利標示為準」。即：**OGDL 標籤是建檔單位（馬祖物件為連江縣政府文化處，推定）在貢獻時給出、網站做對照呈現**；本輪**未讀到**「給出時間」與「具體依據文件」（`lastUpdateDate` 樣本 id 18595 為 2020-08-27，僅代表該筆最後更新，不代表授權標示時間）。
- 馬祖系列描述自述來源：月子餐稱「依據游桂香《傳統馬祖月子餐》一文」；婚宴菜稱「依據陳高志《馬祖傳統婚宴及菜餚簡介》」；月子餐總述 4428 稱 2017–2018 年連江縣政府文化處為執行《博物館與地方文化館發展整合協作平臺計畫》…（已讀開頭）。→ 這些文字有**第三方作者**（游桂香、陳高志），連江縣政府（文化處）是否取得其公開授權**未核實**。

**判斷（意見，非事實）**

- **不必然矛盾**：連江縣政府文化處與建設局同屬連江縣政府，「著作財產權管理機關＝連江縣政府」與「建檔單位連江縣政府文化處標 OGDL」可相容；GPI 的「聯絡處室建設局」只是洽詢授權的窗口，並非排除公眾授權；GPI 欄位本身也不是授權聲明。但 GPI 資料**沒有任何公眾授權的記載**，兩者**無法互相印證**。
- 風險來源：(1) 若記憶庫的食譜文字其實逐字取自 2010 年紙本書，而紙本書版權另由編著者／受託廠商（如作者群）保有、縣政府未取得可再轉授權，則 OGDL 標示可能無效；(2) 月子餐、婚宴菜文字源自第三方文章，轉授權鏈未明；(3) 記憶庫使用條款自我免責（現況提供、不保證不侵權）；(4) OGDL 對使用者**限於依原發布者指示顯名並自負責任**。
- 建議採信順序：**以記憶庫逐物件的授權標示為操作依據**（它是政府機關在貢獻條款下的明示公眾授權，且 OGDL 為政府資料開放授權，由機關擔保有權），但仍視為**有殘餘風險**：風險評估「**低至中**」——被索償機率低（政府標示、顯名即可），惟若出版品版權另有他人則存在被主張侵權的可能；緩解辦法：只存食材名稱（事實性資料，著作權保護薄弱）＋標題＋原文連結＋顯名；不複製作法；保留抓取時間與授權標示截圖／JSON 快照；設下架機制。若要消除風險，需向連江縣政府文化處確認——但用戶已決定不寄授權信，故**列為需人工決定**。

### E5. 內容適配（客觀描述，不作健康結論）

- 馬祖系列自述特色：「食材以海鮮為主，擅長使用米醋、酒糟（又稱紅糟）、以老酒入菜」（3945 描述）。已讀食材清單實見：花蛤、黃魚、海鰻、蝦皮、蝦仁、紅蟳（甲殼類／貝類／魚類）、紅糟／酒糟、老酒／米酒、麻油、豬油、鴨蛋、麵粉類、蝦米、香菇、花生油、醬油等。
- 對過敏原提示的影響：魚、甲殼類、貝類（軟體類）、蛋、含麩質穀物、花生（月子餐用花生油）、大豆（醬油）、芝麻（麻油）在已讀樣本中均出現；紅糟、老酒、米醋屬發酵／含酒精食材（與「組織胺」「酒類」標籤可能有關，須參照 `docs/RATING_CRITERIA.md`，此處不下結論）。月子餐系列另述加入「各種溫補、熱補的中藥材」——中醫說法，只可作傳統說法，不影響評級。
- 描述性結論：此來源食譜多以海鮮、酒糟、老酒為主，與「低致敏原」取向的食譜庫重疊不多；主要價值是**食材→致敏原對應範例**與**傳統食材詞庫／同義詞（紅糟＝酒糟、老酒）**。已讀樣本中尾梨糕（僅太白粉、白糖）屬少數不含海鮮者。
