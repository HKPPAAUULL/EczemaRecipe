# 食材濕疹評級準則（RATING_CRITERIA）

> 本準則是 `ingredient.eczema_rating` 的唯一標準。所有評級先為「草稿（reviewed=false）」，經人工審核才可公開。
> 任何評級變更須更新本文件，並同步於 `docs/PLAN.md` §13 記錄。

## 1. 基本立場（保守、誠實）

- 濕疹的食物誘因因人而異。對**沒有確診食物過敏**的人，一般不建議盲目戒口；戒口可能導致營養不足。
- 食物與濕疹的關係，高質量證據主要來自「已確診（IgE 介導）食物過敏」的兒童，尤其是蛋、牛奶、花生、小麥、大豆等。組織胺、水楊酸、鎳等飲食限制的證據有限，只作「留意」，不作建議戒口。
- 傳統說法（如中醫「發物」）不屬實證證據，若要顯示，須標明「傳統說法」，不得單獨作為評級理由。
- 網站所有文字用語：「常見」「可能」「因人而異」；禁止「治療」「根治」「會導致」等絕對或療效用語。

## 2. 評級定義

| 等級 | 代碼 | 顯示 | 定義 |
|---|---|---|---|
| 🟢 | `suitable` | 一般適合 | 非九大過敏原；無已知與濕疹明顯相關的高組織胺／高致敏性證據；可作日常食材。**不代表對所有人都無過敏**。 |
| 🟡 | `caution` | 因人而異 | 符合任一項：九大過敏原之一；高組織胺食物或會促進組織胺釋放；高水楊酸或高鎳（只作留意）；與常見花粉有交叉過敏；加工食品含大量添加劑。提示：已確診過敏者應避免，其他人可在觀察下少量嘗試。 |
| 🔴 | `trigger` | 常見誘發 | **保留給有權威來源明確指出與濕疹發作有強關聯的情況**（例如指引或系統性綜述，且針對已確診過敏族群）。必須有至少一個權威來源＋人工審核。草稿階段若認為應列 🔴，須在備註標明 `needs_senior_review`。預期只有極少數食材。 |
| ⚪ | `unrated` | 資料不足 | 尚無足夠資料；網站不顯示結論，只顯示營養資料。 |

評級規則：
- 預設不得為 🟢 以外的其他等級而沒有理由；`caution`、`trigger` 必須有 `rating_reason`（資料庫 CHECK 約束已要求）。
- 九大過敏原食材預設至少為 🟡，原因須寫成「為常見食物過敏原之一；已確診過敏者須避免」。
- 同一食材不同形態（例如生蛋、蛋白粉、含蛋加工品）分開列出或在原因中說明。
- 營養亮點（Omega-3、維他命D、鋅、益生元／益生菌等）只作補充資訊，**不改變評級**，也不得宣稱「抗濕疹」。

## 3. 原因文字規格（`rating_reason`）

每個 🟡／🔴 的原因包含：
1. 一句結論（≤40 字，保守用語）
2. 依據類別（過敏原／組織胺／水楊酸／鎳／交叉過敏／其他）
3. 適用對象（例如「已確診蛋過敏者」）
4. 至少一個來源 ID（對應 `evidence`），來源類型優先順序：臨床指引或系統性綜述 > 政府／專業學會（如香港衞生署、食安中心、台灣衛福部、各兒科／過敏專科學會）> 醫院衛教 > 其他（僅作輔助，不單獨支持評級）。

## 4. 來源可信度

- 可引用：PubMed 索引文獻、臨床指引、政府與醫院官方資料、USDA/食安中心/TFDA 成分資料庫。
- 不可引用：AI 生成內容網站、內容農場、商業產品推廣文、無署名的養生文章、社群貼文。
- 每筆草稿必須記錄來源網址；找不到可靠來源 → 評級設為 `unrated`，不要硬猜。

## 5. 審核流程

1. 草稿（`reviewed=false`）：由資料管線或人工草擬，附來源。
2. 審核：由你（或營養師／醫護朋友，如有）逐項確認，填 `reviewed_at`。
3. 公開：只有 `reviewed=true` 的列會出現在網站（view `published_ingredient`）。
4. 每半年或有新指引時覆核；網站頁面顯示「最後審核日期」。

## 6. 食譜的濕疹友善分數（概念，開發食譜階段再細化）

- 食譜含九大過敏原食材 → 顯示過敏原標籤，不自動扣到「不友善」，因為對沒有過敏的人是正常食譜。
- 配對時，若用家勾選了某過敏原，含該過敏原的食譜排除或明確警示。
- 友善分數只反映：少加工、少糖少鹽、烹調方式（蒸、煮、燉優於炸）、食材多樣；**不宣稱療效**。
