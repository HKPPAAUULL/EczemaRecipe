# 種子食材草稿（ingredients_draft.csv）

> **⚠️ 全部內容均為「草稿」，必須經人工（最好有營養師／醫護）逐項審核後才可公開。** 本檔不是醫療建議；沒有任何項目宣稱治療或抗濕疹功效。

## 產生方式
- 依 `docs/RATING_CRITERIA.md` 及 `docs/PLAN.md` §5 草擬，共 163 項（肉類15、海鮮20、蔬菜40、水果25、穀物主食15、蛋奶8、豆類及豆製品10、堅果種子8、調味料12、油脂5、飲品5）。
- 九大過敏原食材一律至少 `caution`；本草稿**沒有任何 `trigger`**（無指引明確支持）。
- 無過敏原、無來源可支持留意標籤的普通肉菜果 → `suitable`（附標準短註，無來源）；找不到可靠來源的非顯而易見項目 → `unrated`。
- 「高組織胺／高水楊酸／高鎳／花粉交叉」標籤只在下列來源有提及時才加，且全部標 `needs_senior_review=true`（組織胺資料各來源不一致）。
- 來源網址是檢索時實際讀到內容（摘要／節錄）的頁面；PubMed 個別頁面因 cookie 限制未能開啟全文，只讀到搜尋結果摘要，審核時請逐一開啟核對。
- `_gen.py` 為產生 CSV 的腳本（可刪）。

## 其他標記 needs_senior_review=true 的項目（caution）

原因主要為：高組織胺／水楊酸／鎳標籤證據弱或各來源不一致；軟體類（貝類）不在九大清單；蛋、奶、花生為最需審慎措辭的項目；芝麻／麻油未有已開啟來源。
